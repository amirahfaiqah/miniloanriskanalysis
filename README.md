# Loan Risk Analysis Dashboard

## Overview
This project analyzes loan applicant data to identify key factors affecting loan eligibility and loan default risk. The analysis was presented using Power BI dashboards and data storytelling to support business decision-making.

The project focuses on understanding how factors such as credit history, self-employment status, household income group, and property area influence loan approval and default outcomes.

## Business Problem
Financial institutions need to evaluate loan applicants carefully to reduce default risk while still supporting eligible applicants. This project aims to answer:

- What factors influence loan eligibility?
- What factors are associated with loan default?
- How can loan approval decisions be improved using data insights?

## Objectives
- Analyze loan applicant characteristics
- Identify factors related to loan approval status
- Identify factors related to loan default risk
- Build an interactive Power BI dashboard
- Present business recommendations based on the analysis

## Dataset Features
The dataset includes loan applicant information such as:

| Feature | Description |
|---|---|
| Gender | Applicant gender |
| Marital Status | Applicant marital status |
| Income / Household Group | Applicant income category such as B40, M40, T20 |
| Loan Details | Loan-related information |
| Credit History | Applicant credit history status |
| Self-Employment | Whether applicant is self-employed |
| Property Area | Urban, semiurban, or rural area |
| Loan Status | Loan approval outcome |
| Loan Default | Default status |

## Key Insights

| Insight | Explanation |
|---|---|
| Credit history is a major factor | Applicants with stronger credit history showed better loan approval outcomes and lower default risk |
| Self-employment affects loan risk | Self-employed applicants showed different loan approval and default patterns across household income groups |
| Property area matters | Loan approval and default trends differed across semiurban, urban, and rural applicants |
| Household income group affects interpretation | B40, M40, and T20 groups showed different patterns in approval and default behavior |

## Business Recommendations

| Recommendation | Purpose |
|---|---|
| Prioritize credit history in loan evaluation | Credit history was one of the strongest indicators of loan status and default risk |
| Promote responsible credit-building programs | Encourage applicants to build credit history through suitable financial products |
| Review self-employed applications carefully | Self-employed applicants may require additional income verification or risk checks |
| Support eligible rural/B40 applicants | Improve financial inclusion while still monitoring default risk |
| Use gamification for repayment behavior | Reward timely repayments to encourage better repayment habits |

## Limitations
- The project focuses on dashboard-based analysis, not predictive machine learning.
- Results depend on the available dataset features.
- Some business recommendations require further validation with larger or real-world financial datasets.
